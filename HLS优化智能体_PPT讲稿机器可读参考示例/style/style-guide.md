# 风格说明

## 核心视觉系统

- 画布：16:9，1280×720 渲染基准。
- 主色：深橄榄绿 `#445437`；强调黄 `#FFCC00`。
- 辅助色：蓝 `#2872A1`、橙 `#FCB322`、深橙 `#EA6C00`、绿色 `#70AD47`。
- 主题字体：中文以 Microsoft YaHei/微软雅黑为主，西文以 Arial 为主，代码与公式标签可使用 Consolas。
- 标题：大号深绿色、左对齐；右上角维持学校标识。
- 正文：黑色或灰绿色；关键结果用深绿、黄色或砖红色突出。
- 背景：浅灰白纹理或低对比度校园照片；避免背景抢夺信息层级。

## 版式模式

- 封面/结束页：左侧文字、右侧校园照片。
- 概念说明页：左侧问题或公式，右侧约束、表格或例证。
- 决策/工作流页：主流程居中或铺满页面，下方用深蓝结论条收束。
- 结果页：矩阵/表格为主体，用黄色标出关注项、砖红标出短板、深绿标出优势。
- 结论页：创新点与局限性双栏，下方给出下一步计划。

## 复用规则

1. 先选择叙事角色相同的源页，再复制源页并修改已有元素。
2. 保留源页字体、字号、行距、边距、对齐、颜色、页脚和标识。
3. 内容放不下时优先删减、换版式或拆页，不通过显著缩小字体硬塞。
4. 数据和真实世界证据必须重新核验，并在备注中加入 `[Sources]`。
5. 不要照搬源文件中的视觉缺陷；详见 `qa/source-quality-notes.md`。
