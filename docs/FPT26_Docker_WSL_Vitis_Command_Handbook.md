# Docker + WSL + Vitis HLS 查询手册

适用于 FPT26 Track A / LLM4HLS Agent 项目开发环境。

------------------------------------------------------------------------

# 1. Docker 基础概念

## Image（镜像）

镜像是 Docker 环境模板。

例如：

    vitis_runtime:2023.2

由：

    vitis.dockerfile
            |
            v
    Docker Image

生成。

------------------------------------------------------------------------

## Container（容器）

容器是镜像运行后的实例。

关系：

    Image
     |
     v
    Container

一个 image 可以创建多个 container。

------------------------------------------------------------------------

# 2. Docker 状态查看

```

------------------------------------------------------------------------

## 查看Docker详细信息

```

------------------------------------------------------------------------

# 3. Image管理

## 查看已有镜像

``` bash
docker images
```

或：

``` bash
docker image ls
```

------------------------------------------------------------------------

## 构建镜像

常用于构建Vitis环境：

``` bash
docker build -t 镜像名:标签 -f Dockerfile路径 .
```

例：

``` bash
docker build \
-t vitis_runtime:2023.2 \
-f vitis.dockerfile .
```

------------------------------------------------------------------------

## 删除镜像

查看：

``` bash
docker images
```

删除：

``` bash
docker rmi IMAGE_ID
```

------------------------------------------------------------------------

## 拉取镜像

``` bash
docker pull IMAGE
```

例：

``` bash
docker pull ubuntu:22.04
```

------------------------------------------------------------------------

# 4. Container管理

## 查看运行中的容器

``` bash
docker ps
```

------------------------------------------------------------------------

## 查看所有容器

包括停止：

``` bash
docker ps -a
```

------------------------------------------------------------------------

## 创建并进入容器

``` bash
docker run -it IMAGE bash
```

例：

``` bash
docker run -it vitis_runtime:2023.2 bash
```

参数：

    -i interactive
    -t terminal

------------------------------------------------------------------------

## 后台运行

``` bash
docker run -d IMAGE
```

------------------------------------------------------------------------

## 停止容器

``` bash
docker stop CONTAINER_ID
```

------------------------------------------------------------------------

## 启动已有容器

``` bash
docker start CONTAINER_ID
```

------------------------------------------------------------------------

## 删除容器

``` bash
docker rm CONTAINER_ID
```

强制删除：

``` bash
docker rm -f CONTAINER_ID
```

------------------------------------------------------------------------

## 进入运行中的容器

``` bash
docker exec -it CONTAINER_ID bash
```

------------------------------------------------------------------------

## 查看日志

``` bash
docker logs CONTAINER_ID
```

------------------------------------------------------------------------

# 5. 文件挂载

用于：

宿主机代码

↓

Docker容器

命令：

``` bash
docker run \
-it \
-v 宿主路径:容器路径 \
IMAGE bash
```

例：

``` bash
docker run \
-it \
-v $(pwd):/workspace \
vitis_runtime:2023.2 \
bash
```
