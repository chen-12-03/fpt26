\section{Reproduction}
\label{app:reproduction}

Task list: \path{tasks/track_a_150/candidate_manifest.json}.
Campaigns: \path{runs/150_ultimate/}. Run
\path{python3 technical-paper/scripts/update_results.py} from the
repository root to refresh macros; the script validates model identity,
task count, API client, execution-source hash, and credit limit before
emitting output.

All campaigns: source snapshot {\small\ExecutionSourceHash},
temperature~0, 4,096-token output limit, 180\,s request timeout, $\leq$2
retries.
