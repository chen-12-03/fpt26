\section{Reproduction and Result Refresh}
\label{app:reproduction}

The accepted task list is
\texttt{tasks/track\_a\_150/candidate\_manifest.json}. The three source report
paths are written as comments at the end of
\texttt{technical-paper/results\_generated.tex}. After replacing or extending
matching directories under \texttt{runs/}, execute
\texttt{python3 technical-paper/scripts/update\_results.py} from the repository
root. The script selects the latest matching final report and refuses to emit
macros unless model identity, task count, real-API status, execution-source
hash, and credit limit agree.

The generated file supplies task counts, result prose values, and all detailed
table rows. A refreshed campaign therefore updates numerical evidence without
hand-editing the paper. The two PDF figures are intentionally separate vector
assets and must be regenerated from the same report set before final
submission. Evaluator-only tests and references remain outside the
agent-visible filesystem; report writers redact credentials and sensitive
paths.
