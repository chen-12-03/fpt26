\section{Independent Checks Separate Three Objectives}
\label{sec:evaluation}

\textbf{Protocol.} Three hosted endpoints process the same balanced
\CorpusTaskCount{}-task suite under one agent revision and the Track-A
contract~\cite{fpt26tracka}. Submission-side synthesis provides public-gate
completion and a starter-anchored QoR proxy. A fresh evaluator reruns all
\IndependentEvaluatedCount{} public-completed kernels with hidden \CSim,
synthesis, and required hidden \CoSim, then computes reference-anchored QoR
when fixed reference metrics exist. Both QoR measures apply
Eq.~\eqref{eq:score}; the 25 optimization tasks (QoR-25) have complete coverage.

\textbf{Results.} Table~\ref{tab:headline-results} yields three patterns.

(1)~\textbf{No hidden failures appear.} All
\IndependentHiddenCorrectCount{}/\IndependentEvaluatedCount{} kernels pass
evaluator-side hidden correctness. Qwen3.6-27B supplies the largest evaluated
set (\QwenThreeSixSuccessCount{}/\CorpusTaskCount{} public completions),
including all 25 structural \CoSim{} tasks.

(2)~\textbf{DeepSeek leads both QoR-25 measures.} The shared denominator makes
the endpoints directly comparable, and changing from the starter to the
reference anchor preserves their ordering: DeepSeek, Qwen3.6, then Qwen3.5.

(3)~\textbf{No endpoint dominates every objective.} Qwen3.6 leads public-gate
completion, DeepSeek leads QoR-25, and Qwen3.5 minimizes token use. One
campaign per endpoint prevents architecture attribution.
