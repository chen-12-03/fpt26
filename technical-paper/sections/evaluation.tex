\section{Qwen3.5 Leads This Endpoint Run Set}
\label{sec:evaluation}

\textbf{Protocol.} Three hosted endpoints process the same balanced
\CorpusTaskCount{}-task suite under one agent revision and
\CampaignCreditLimit{}-credit limit. Each completed output must pass \CSim,
\Synth, 100 MHz, U55C capacity, and every applicable \CoSim{} gate under the
Track-A contract~\cite{fpt26tracka}. Audit-clean success also excludes any
task with a failed API request. Appendix~\ref{app:benchmark} gives task
provenance; Appendix~\ref{app:results} gives score and cost details.

\textbf{Results.} Qwen3.5 records
\QwenThreeFiveSuccessCount{}/\CorpusTaskCount{} audit-clean successes and the
highest score sum, \QwenThreeFiveScoreSum. DeepSeek completes
\DeepSeekRunCompletedCount{} tasks but passes the API audit on
\DeepSeekSuccessCount{}; it still has the highest scored-task mean,
\DeepSeekScoredMean. Qwen3.6 encounters failed requests on
\QwenThreeSixApiAffectedTaskCount{} tasks, and
\QwenThreeSixZeroResponseFailedCount{} tasks fail without a response.
Conditional means cover different subsets, while unequal provider failures
confound model-weight comparisons.

\takeaway{Qwen3.5 provides the strongest deployed endpoint in this run set.
DeepSeek's higher conditional mean still yields a lower aggregate score.}
