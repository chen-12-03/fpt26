High-level synthesis (HLS) agents must repair and optimize unfamiliar kernels
within limited model and tool budgets. The Verified-Candidate Loop (\VCL) lets
validation evidence control candidate promotion. Its quality-of-results (QoR)
score aggregates effective latency, capacity-normalized resource footprint, and
source-change evidence into a single bounded utility. QoR-guided
retrieval-augmented generation (QoR-RAG) reuses compatible evidence, and
Failure Reflection turns tool diagnostics into the next constraint without
extra model calls. We evaluate three open-weight large language model endpoints
on a balanced 150-task suite spanning six HLS capabilities. We report
public-gate completion and a starter-anchored QoR proxy from submission-side
synthesis. Qwen3.6-27B achieves the highest completion rate
(\QwenThreeSixSuccessRate, \QwenThreeSixSuccessCount{}/\CorpusTaskCount{}
tasks). DeepSeek V4 Pro leads the 25-task optimization proxy
(\DeepSeekQorProxy{}) while consuming \DeepSeekTokensM{}M tokens.
Qwen3.5-122B-A10B uses the fewest tokens. These single campaigns support
endpoint-level comparison; architecture attribution requires controlled
repeated trials.
