\section{Conclusion}

The \VCL{} preserves a verified fallback under finite validation gates. Across
one campaign per configuration, completion ranges from 140/150 to 143/150; all
424 outputs that pass the public gates also pass our evaluator-side held-out
suite, which is not the organizer's final hidden benchmark. Qwen3.5 has the
highest paired composite-score means (77.77/78.93), whereas DeepSeek uses the
fewest observed tokens.

All configurations complete 25/25 synthesis-repair tasks; DeepSeek, Qwen3.5,
and Qwen3.6 respectively lead functional repair (22/25), code generation
(25/25), and structural repair (25/25).

These results describe deployed configurations rather than causal model
effects. The public repository provides code, run records, and aggregation
scripts. Repeated campaigns, component ablations, and score-sensitivity studies
remain future work.
