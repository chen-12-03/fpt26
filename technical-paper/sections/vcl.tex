\section{Tool Evidence Controls the Agent Workflow}

The task interface supplies one editable kernel, its top-function signature,
public tests, target part, and budgets. Through one tool interface, the agent
submits a complete source file, requests validation, and reads a structured
report; it never receives hidden tests or frozen references. Preflight rejects
malformed inputs before the LLM or HLS tools consume budget. The controller
records every candidate, gate, metric, token, and credit in one run state.

The \VCL{} runs interface checks, C simulation (\CSim), HLS synthesis
(\Synth), the 100 MHz frequency check, the U55C capacity check, task-required
C/RTL co-simulation (\CoSim), and metric-completeness checks. Let each
applicable gate $G_i\in\{0,1\}$. We set an inapplicable \CoSim{} gate to one:
\begin{equation}
V(c)=G_{\mathrm{int}}G_{\mathrm{csim}}G_{\mathrm{syn}}
  G_{\mathrm{freq}}G_{\mathrm{cap}}G_{\mathrm{cosim}}G_{\mathrm{metric}}.
\label{eq:validity}
\end{equation}
Let $b$ denote the verified fallback. The promotion rule is
\begin{equation}
P(c)=V(c)\land[\QHW(c)>\QHW(b)].
\label{eq:promotion}
\end{equation}
Budget admission reserves the credits for all required gates. A failed gate or
budget denial retains $b$. QoR-RAG supplies version-compatible rules,
successes, and measured failures. Failure Reflection converts bounded
diagnostics and the candidate diff into the next constraint without another
LLM request. Duplicate fingerprints and repeated failure signatures stop
unproductive retries. Hidden acceptance remains an evaluator-side check.
