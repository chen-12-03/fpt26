# License texts

This directory contains the license texts required by the frozen Track-A v4
corpus. Standard texts use their SPDX identifiers as filenames. The two
upstream-specific texts use `LicenseRef-` names that match the evaluator
mapping.

The root `LICENSE` applies to original repository code. See
`THIRD_PARTY_NOTICES.md` for the source-suite mapping and task counts.
